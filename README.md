# Robot编排模拟平台（体验版）

一个跑在浏览器里的机器人行为编排 / 预览工具。左边是机器人实时预览，右边分三个模块：

- **场景编排** —— 在 5 条轨道（动作 / 表情 / 配饰 / 氛围特效 / 氛围灯）上排片段，播放看效果
- **音光派对** —— 放一段音乐，实时解析节拍驱动机器人律动
- **感知模拟** —— 模拟传感器事件，看行为决策的优先级仲裁

## 本地运行

纯静态页面，无需构建。因为用了 ES Modules，**不能直接双击 index.html**（浏览器会拦截 `file://` 下的模块脚本），需要起一个本地服务器：

```bash
npx http-server -p 4173 -c-1
```

然后打开 http://localhost:4173
