使用教程

左边是机器人实时预览（三个模块共用，一直在）；右边按顶部 tab 分成三个模块。同一时间只有一个模块在驱动机器人——切 tab 会自动停掉上一个模块。

🎬 场景编排

一份编排 = 5 条轨道同时演出：动作、表情、配饰、氛围特效、氛围灯。每条轨道上排「片段」，共用同一条时间轴。

加片段

  1. 点表头的 ＋ 添加片段 展开表单（默认收起，保持界面清爽）。
  2. 选通道（动作/表情/…），再选原子（具体做什么，比如"转向主驾""开心"）。
  3. 定开始时间，三种方式随便用：
    • 默认接末尾——自动填成该通道最后一个片段的结束时间，连点几次就能一串排下去
    • 点轨道空白处——定位到你点的那个时间（吸附 100ms）
    • 直接输数——要精确到任意毫秒时用
  4. 动作通道还能设角度和速率/幅度/重复/停留四个系数。
两行实时提示很有用：
· 最终角度 = 角度 × 幅度，超出硬件范围会提示截断后的实际值
· 动作预计耗时——动作按限速转到位真正需要多久。时长填得比它短，动作就转不完，会标红并给一个「设为 XXms」一键补足

在时间线上直接改

  • 点片段 → 载入表单精细编辑，按钮变「✓ 保存修改」，改完就地更新
  • 左右拖动 → 粗调开始时间（吸附 100ms，拖动时气泡显示新的起止）
  • 向下拖出 或点片段内的 × → 删除
  • 悬停 → 浮层显示这条片段的全部参数

同一轨道内片段不会重叠：撞上了会自动向后紧贴排布并级联推移。不同轨道之间互不影响，时间点可以刻意错开（动作先转头、表情晚一点再变）。

播放

  • ▶ 播放 / ⏸ 暂停 / ■ 停止。暂停停在当前时刻并保持那一瞬的姿态，方便定住看效果，按钮变「▶ 继续」从原处接着播；停止是回到 0ms 从头来。
  • 拖进度条可以任意定位，所有轨道的播放竖线跟着对齐。

保存与分享

  • ★ 存为模版 / 载入模版：把整套编排命名存下来复用（存在当前这个浏览器里，换电脑会丢）。
  • ↓ 导出 JSON / ↑ 导入 JSON：存成文件，可备份、发给同事、交付给固件。这是平台最终的交付物。
  • 编辑中的内容会自动存草稿，刷新不丢；但正式保存请用模版或导出。

🎵 音光派对

  1. 选音源：本地音频文件 / 麦克风（听外放）/ 浏览器标签页音频。
  2. 点 ♪ 开始律动。
  3. 每个自由度单独设频次和幅度——俯仰点头、歪头摇摆、旋转摆头各自勾选启用。
    例：俯仰「每2拍」+ 旋转「每4拍」→ 转到一边点个头、转到另一边再点个头。
  4. 曲风可手动指定或按节奏自动推测，决定用什么表情和配饰。

麦克风/标签页音源需要浏览器授权，并且必须通过网址访问（本地服务器或线上地址）。

📡 感知模拟

  1. 点 进入模拟，机器人进入待机态。
  2. 触发传感器事件：NFC 配饰贴近/移开、触摸（也可直接点预览里机器人的屏幕）、手势、人脸识别。
  3. 机器人做出对应反应，优先级自动仲裁——比如正在放音乐律动时「识别到主驾」会打断它切去迎宾。下方日志会写清每次触发或忽略的原因。

常见问题

  • 音乐律动没反应：外放音量开大些；确认音源选对；麦克风模式要允许权限。
  • 片段显示成一串英文 ID / 播放时不动：多半是导入了旧版本编排，里面的原子已经改过。载入一次示例编排覆盖即可。
  • 想看有哪些动作/表情/配饰：在添加片段面板里逐个下拉即可预览。
